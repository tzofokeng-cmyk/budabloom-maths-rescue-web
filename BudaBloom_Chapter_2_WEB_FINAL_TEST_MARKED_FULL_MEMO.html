Topic 1: What Is an Algebraic Expression?

Learn

An algebraic expression is a maths phrase made from numbers, letters and operations such as +, −, × and ÷.

An expression does not need an equals sign.

Worked example

2x + 5 is an algebraic expression.

It has a number, a letter and a plus sign. There is no equals sign.

Q1.

Which is an algebraic expression?

Topic 2: Variables, Coefficients and Constants

Learn

Variable: a letter that stands for a number.

Coefficient: the number multiplying the variable.

Constant: a number standing alone.

Example: 4x + 7
x = variable
4 = coefficient
7 = constant
Q1.

In 6y + 3, what is the variable?

Topic 3: Writing Expressions From Words

Learn the words

plus / added to / more than → add

minus / take away → subtract

times / multiplied by → multiply

Worked example

“7 more than a number”

Step 1: Let the number be x.

Step 2: “more than” means add.

Step 3: x + 7.

Q1.

Which expression means “3 times a number”?

Topic 4: Substitution

Learn

Substitution means replacing a letter with the number given.

Worked example — How did we get there?

Find 3x + 2 when x = 4.

Step 1: Replace x with 4.

3(4) + 2

Step 2: Multiply 3 × 4 = 12.

12 + 2 = 14.

Q1.

Find 2x + 3 when x = 4.

Topic 5: Calculate an Expression Carefully

Learn

After substitution, multiplication or division comes before addition or subtraction.

Worked example — How did we get there?

Find 2x + 5 when x = 6.

Step 1: Replace x with 6 → 2(6) + 5.

Step 2: Multiply first → 12 + 5.

Step 3: Add → 17.

Q1.

Find 5x + 1 when x = 3.

Topic 6: Check Your Expression and Answer

Learn

Check that you used the correct operation, replaced the letter correctly, and calculated each step carefully.

Worked example — How did we get there?

For 3x + 2 when x = 4:

3 × 4 + 2 = 12 + 2 = 14.

Check: x was replaced by 4 everywhere it appeared.

Q1.

For x = 4, what is 3x + 2?
