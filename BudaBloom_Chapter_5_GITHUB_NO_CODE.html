Chapter 5: Multiplication of Algebraic Expressions

Simple steps. Easy understanding.

🧠 Start with 2x³

Let's break 2x³ into three simple parts.

2 = the number (also called the coefficient)
x = the base
3 = the index / exponent

2x³ = 2 × x × x × x

Important: The 3 tells us how many times x is multiplied by itself. It does NOT mean 2 is cubed.

Easy way to remember

NUMBER → 2
BASE → x
INDEX / EXPONENT → 3

So when you see 2x³, think: 2 × x × x × x.

How to answer: Look at the number directly in front of the variable. Type only that number.
Practical: What is the coefficient in 2x³?

🔎 One more example

Look at 5y²:

5 = number / coefficient
y = base
2 = index / exponent

5y² = 5 × y × y

⭐ The index rule

When multiplying powers with the same base, ADD the indices.

x² × x³ = x⁵
Why?
x² = x × x
x³ = x × x × x
Together = x × x × x × x × x = x⁵
2 + 3 = 5
BudaBloom shortcut:
Same base + multiplication → ADD the indices.
How to answer: The coefficient is the number in front of the variable.
Look at the number directly before x and type that number only.
Question 2: What is the coefficient in 5x²?
How to type your answer:
If your answer contains a power, type the variable first, then ^, then the power.
For example, write y² as y^2.
If there is a number in front, keep it too: write 2y³ as 2y^3.
Practical: x² × x³ = ?

1. Monomial × Monomial

Multiply the numbers first. Then multiply the variables.

3x × 4x²
Step 1: 3 × 4 = 12
Step 2: x × x² = x³
Step 3: 12x³
How to answer: Multiply the numbers first. Then multiply the variables. For powers, use ^. Example format: 3x^2.

✖️ Sign rule

+ × + = +
+ × − = −
− × + = −
− × − = +
How to answer: Work out the signs first. Then multiply the numbers and variables. Keep the variable in your answer. For a power, use ^. Example format: 3y^2.
Question 2: 2x² × 5x = ?
Practical: 3x × (−4x²) = ?

2. Monomial × Binomial

Multiply the outside term by every term inside the bracket.

3x(x + 4)
3x × x = 3x²
3x × 4 = 12x
Answer: 3x² + 12x
How to answer: Multiply the term outside the brackets by every term inside. Write every term in your answer. Use ^ for powers.
Question 2: (−2x²) × (−5x) = ?
Practical: 4x(x + 2) = ?

3. FOIL

For two binomials, FOIL helps us multiply every pair.

First   Outer   Inner   Last
(x + 2)(x + 3)
First: x × x = x²
Outer: x × 3 = 3x
Inner: 2 × x = 2x
Last: 2 × 3 = 6
Answer: x² + 5x + 6
How to answer: Multiply First, Outside, Inside and Last. Then combine like terms. Use ^ for powers.

Practical: (x + 2)(x + 3) = ?
